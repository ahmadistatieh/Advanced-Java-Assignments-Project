# Advanced Java Assignments Project

This repository contains advanced Java assignments focused on object-oriented programming, refactoring, clean code structure, and design patterns.

## Topics Covered

- Object-Oriented Programming (OOP)
- SOLID Principles
- Code Refactoring
- Design Patterns
- Strategy Pattern
- Proxy Pattern
- Decorator Pattern
- Observer Pattern
- Template Method / Template Registry
- Factory-based object creation
- Basic database abstraction
- UML documentation
- Git and GitHub workflow

## Project Structure

### Assignment 1 - Refactoring and Design Improvement

This assignment focuses on improving an existing Java application by applying refactoring techniques and better code organization.

Main concepts:
- Separation of responsibilities
- Connection pool abstraction
- Job execution flow
- Strategy pattern for different job types
- Proxy pattern for controlled execution
- Template registry for reusable job templates

### Assignment 2 - Event Processing System

This assignment implements an event processing system using multiple design patterns and layered structure.

Main concepts:
- Event processing pipeline
- Observer pattern for event notifications
- Decorator pattern for logging behavior
- Strategy pattern for processing actions
- Factory pattern for event type handling
- Database abstraction layer
- UML documentation
